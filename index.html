Keyboard controls

Use arrow keys or WASD for directions. Enter = Cross, Backspace = Circle, Q = Square, E = Triangle, U/O = L1/R1, I/P = L2/R2, Space = PS. Click here first if keyboard input is not responding.

Connection help

This version is a UI demo only. It does not send controller inputs over USB or Bluetooth and does not implement PS Remote Play.

  • A USB-A to USB-C cable by itself does not make a webpage act as a DualShock 4 controller.
  • Remote Play requires being enabled and configured on the PS4, plus a supported client and account setup.
  • If the console's only working controller is unavailable and Remote Play is not enabled, you may need to borrow a compatible controller briefly to configure it.
